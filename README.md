# Lakeside Resort IT Assistant · 湖畔渡假村 IT 小幫手

The buttons in the Lakeside Resort iStaging tours open these pages.

- When the presenter's laptop is on and its assistant is ready, every page goes on to the live IT Assistant and mini-games
  running there.
- Otherwise a saved copy opens: the map, the overview of every place (recorded on 2026-11-22), Progress, How it works and the
  four mini-games work. New questions to the AI, and reporting the security weaknesses you find, need the laptop.

iStaging 導覽裡的按鈕會打開這裡的網頁。報告用的筆電開著、小幫手也準備好時，每一頁都會轉到筆電上的 IT 小幫手和小遊戲；
否則會打開存好的離線版：地圖、每個地點的介紹（2026-11-22 錄的）、「進度」、「原理」和四個小遊戲都能用，
問 AI 新的問題、回報找到的資安漏洞要等筆電開著。

To see the saved copy, add `?offline` to an address here (`&offline` if it already has a `?`).
這裡的網址後面加 `?offline`（已經有 `?` 的加 `&offline`）可以直接看離線版。
