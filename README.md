# Lakeside Resort IT Assistant · 湖畔度假村 IT 小幫手

The buttons in the Lakeside Resort iStaging tours open these pages.

- When the team's laptop is on, every page goes on to the live IT Assistant and mini-games running on it.
- When it is off, a saved copy opens: the map, the overview of every place (recorded on 2026-11-22), Progress,
  How it works and the four mini-games work. New questions to the AI need the laptop.

iStaging 導覽裡的按鈕會打開這裡的網頁。組員的筆電開著時，每一頁都會轉到筆電上的 IT 小幫手和小遊戲；
筆電沒開時會打開存好的離線版：地圖、每個地點的介紹（2026-11-22 錄的）、進度、原理說明和四個小遊戲都能用，
問 AI 新的問題要等筆電開著。

Add `?offline` to any address to see the saved copy. 任何網址後面加 `?offline` 可以直接看離線版。
